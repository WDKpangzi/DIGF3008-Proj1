# Memory Map

A personal memory map for mobile. Give your phone three gentle shakes to travel from one place to the next; each shake moves a small footprint along the route. At each stop, use the top **EXIT** button to return to the map. Tilt or swipe to browse photos. An on-screen control is available as a fallback.

## Preview locally

Open `index.html` in a browser. Some mobile browsers only provide motion sensors on HTTPS pages, so use the on-screen control to preview the route when opening the local file.

## Publish with GitHub Pages

1. Upload the complete contents of the `memory-map` folder to a GitHub repository.
2. In the repository, open **Settings → Pages** and choose the branch and folder to publish (the repository root or `/docs`).
3. Save, then open the generated HTTPS address on a phone. Tap **Begin the Journey** and allow motion and orientation access.

The photos were provided by the user and are included with the site. Publishing the repository and site makes these photos publicly accessible.
